Configurer les contrôles

Les colonnes sont détectées depuis la première ligne du fichier.

Contrôles à lancer
Les en-têtes comme « CP », « Code postal », « ZIP » et « Postcode » sont présélectionnés. Ajustez la sélection selon le fichier. Ctrl (Windows) ou Cmd (Mac) permet d’en choisir plusieurs.
Cette version contrôle la forme du code, pas son existence dans une base postale.
Si le fichier contient une colonne « Pays », « Country » ou « Country code », le pays peut être lu pour chaque ligne. Valeurs comme France, FR ou FRA reconnues.
Maintenez Ctrl (Windows) ou Cmd (Mac) pour en choisir plusieurs.
